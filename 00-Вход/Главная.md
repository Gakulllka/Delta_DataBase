# DataBase — база знаний Delta

> Единый источник правды для экосистемы **Delta**. Здесь всё теоретическое: дизайн-система, описания продуктов, журнал ошибок, шаблоны. Код и промпты для агентов лежат **вне** этого vault — рядом с проектами.

## Ключевые принципы Delta

1. **Монохром** — чернила на бумаге, цвет только для смысла
2. **Графитовая рельса** — фирменная «дверь» `#17181C`
3. **Geist** — шрифт всех продуктов
4. **Воздух** — щедрые отступы, чистые поверхности

---

## Правила ведения vault

- **Только проверенное.** Утверждение попадает сюда, если подтверждено кодом или конфигом. Непроверенное помечается явно.
- **Дата сверки обязательна.** У каждой карточки — `updated` и строка «Сверено с кодом».
- **Код меняется → карточка меняется в том же заходе.**
- **Ссылки только рабочие.** Битая `[[ссылка]]` хуже её отсутствия.
