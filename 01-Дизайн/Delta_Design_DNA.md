# ДНК Delta — фирменный стиль и дизайн-система

> Переносимый бренд-гайд семейства продуктов **Delta**. Дистиллирован из эталонной реализации (Delta Tasker). Применяй как единый источник визуального языка для любого нового продукта Delta — так они узнаются как «одна компания».
>
> **Кодовое имя темы:** «Графит и бумага». **Версия:** 1.1.

---

## 1. Суть за 30 секунд

Delta — это **чернила на бумаге**. Строгий, спокойный, профессиональный интерфейс, где ничего не отвлекает от сути. Один характер в двух режимах: светлый — тёплая **бумага** и графитовые **чернила**; тёмный — **графит** и бумажный текст.

Три правила, по которым Delta узнаётся мгновенно:

1. **Монохром по умолчанию.** Акцент = чернила (почти чёрный) в светлой теме и бумага (почти белый) в тёмной. Кнопки, активные элементы, метки — чёрно-белые.
2. **Цвет — только у смысла.** Единственное место, где появляется цвет, — семантика: статусы, прогресс, опасность. Больше нигде. Никаких декоративных градиентов и разноцветных акцентов.
3. **Фирменная «дверь» — графитовая рельса.** Тёмный графитовый навигационный элемент (`#17181C`) с моно-«бровями» капсом и белой плашкой активного пункта. Он всегда графитовый — в любой теме.

Ощущение: скандинавский минимализм, много воздуха, деликатные тёплые тени, мягкие скругления, иерархия строится размером и весом шрифта, а не цветом.

---

## 2. Философия (характер бренда)

- **Один характер, два режима.** Не «светлая и тёмная версии разных дизайнов», а одна личность при разном освещении. Светлая = бумага + чернила. Тёмная = графит + бумажный текст.
- **Акцент — это чернила, а не цвет.** Выбор произвольного акцентного цвета в продуктах Delta намеренно **отключён**. У бренда один голос. Активные элементы монохромны.
- **Цвет несёт информацию, а не украшает.** Зелёный = успех, синий = в работе, янтарь = требует внимания, красный = опасность. Если цвет ничего не значит — его не должно быть.
- **Профессиональный инструмент.** Delta — для эксперта за работой. Строго, тихо, надёжно. Не игриво, не «стартап-ярко».
- **Воздух и тишина.** Щедрые отступы, чистые поверхности, почти незаметные тени. Пусть контент дышит.
- **Метафора «фирменной двери».** Графитовая рельса — вход в продукт, узнаваемый порог. Одинаковый во всех продуктах Delta.

## 3. Знак (brand mark)

- **Символ:** треугольник дельты **△** — минималистичный, линейный, ровный.
- **Словесный знак:** `DELTA` — прописными, спокойным гротеском, с лёгкой разрядкой. Рядом с треугольником.
- **Фирменная загрузка (Brand Splash):** отрисовка контура дельты штрихом (анимация «прорисовки»), затем мягкое «дыхание» стека дельт. Графит и бумага. Создаёт узнаваемый момент входа.
- **Правила знака:**
  - [Да] Знак живёт на графите (рельса/шапка) в бумажном цвете `#FAFAF8`, либо на бумаге в чернильном `#17181C`.
  - [Да] Достаточно воздуха вокруг; треугольник ровный, не наклонённый.
  - [Нет] Не окрашивать знак в семантические/произвольные цвета, не добавлять тени/градиенты/объём.
- Файлы знака в проекте: `/logo.svg`, `/favicon.svg` (для нового продукта — воспроизвести в том же стиле).

### 4.3. Рельса и графитовые слои (⚠️ фирменная подпись)
Графитовая рельса и всплывающие из неё меню — **всегда графит, в любой теме**. Это ядро узнаваемости.

| Роль | Токен | Значение |
|------|-------|----------|
| Фон рельсы (графит) | `--rail-bg` | `#17181C` |
| Текст рельсы (бумага) | `--rail-text` | `#FAFAF8` |
| Приглушённый текст рельсы | `--rail-muted` | `rgba(250,250,248,0.74)` |
| Тусклый текст рельсы | `--rail-faint` | `rgba(250,250,248,0.50)` |
| Линия/разделитель рельсы | `--rail-line` | `rgba(250,250,248,0.12)` |
| Ховер пункта | `--rail-hover` | `rgba(250,250,248,0.08)` |
| **Активный пункт** | — | фон `#FAFAF8`, текст `#17181C` (белая плашка, чёрный текст) |

⚠️ Активный пункт навигации — **белая плашка с чёрным текстом**, всегда, независимо от темы. Это одна из самых узнаваемых деталей Delta.

Меню, открывающиеся «с рельсы» (аккаунт, выбор, контекст), тоже графитовые:
- **Ink Pop** (обычное меню): фон `#1C1D22`, текст `#FAFAF8`, граница `rgba(250,250,248,0.14)`.
- **Ink Ctx** (контекстное меню, чистый ЧБ): фон `#0F1013`, текст `#FAFAF8`; ховер пункта — **инверсия**: фон `#FAFAF8`, текст `#0F1013`; «удалить» при ховере — `#FF4444`; радиус 12px.

### 4.4. Семантический слой (единственный цвет в системе)
Цвет допустим **только** для смысла. Палитра — сдержанная, «приглушённо-пастельная», не кричащая. Рекомендованные значения (тон подбирается под продукт, но правило «тихо и по делу» — обязательно):

| Значение | Роль | Свет (текст/акцент) | Мягкий фон плашки |
|----------|------|---------------------|-------------------|
| В работе / выполняется | прогресс, генерация | `#3B82F6` (сдержанный синий) | `rgba(59,130,246,0.12)` |
| Успех / готово / пройдено | статус | `#3F9E6E` (приглушённый зелёный) | `rgba(63,158,110,0.12)` |
| Требует внимания / вопрос | статус | `#C08A2D` (янтарь) | `rgba(192,138,45,0.12)` |
| Опасность / ошибка / провал | статус | `--danger` | `rgba(198,69,63,0.10)` |
| Нейтральное / ожидание | статус | `--text-muted` | `--accent-soft` |

- Плашки-статусы: полностью скруглены (pill), мелкий кегль (~0.65rem), вес 600, мягкий тонированный фон + насыщенный текст того же тона.
- Прогресс-бар: либо монохром (графит), либо «рабочий» синий как единственное цветовое исключение — согласованно во всём продукте.

## 5. Типографика

### 5.1. Шрифты
- **Основной (интерфейс/текст):** **Geist** — чистый современный гротеск, компактный, нейтральный.
- **Моноширинный (числа, ID, «брови»):** **Geist Mono**.
- Подключение (Next.js / `next/font`):
  ```ts
  import { Geist, Geist_Mono } from "next/font/google";
  const geistSans = Geist({ variable: "--font-geist-sans", subsets: ["latin"] });
  const geistMono = Geist_Mono({ variable: "--font-geist-mono", subsets: ["latin"] });
  // <body className={`${geistSans.variable} ${geistMono.variable} antialiased`}>
  ```
- Вне Next: подключить Geist и Geist Mono (например, из `@fontsource`/Google Fonts), задать `--font-geist-sans` / `--font-geist-mono`.
- Всегда `-webkit-font-smoothing: antialiased`.

### 5.2. Фирменные текстовые приёмы (узнаваемость)
- **«Бровь» (eyebrow)** — служебные подписи капсом. Моно, ~10px, вес 600, `text-transform: uppercase`, широкая разрядка. Две версии:
  - на графите (рельса): `letter-spacing: 0.16em`, цвет `--rail-faint`;
  - на бумаге: `letter-spacing: 0.14em`, цвет `--text-muted`.
  ```css
  .eyebrow {
    font-family: var(--font-geist-mono, ui-monospace, monospace);
    font-size: 10px; font-weight: 600;
    text-transform: uppercase; letter-spacing: 0.14em;
    color: var(--muted-foreground);
  }
  ```
- **Числа — моноширинные табличные.** Все метрики, id, счётчики, часы:
  ```css
  .num {
    font-family: var(--font-geist-mono, ui-monospace, monospace);
    font-variant-numeric: tabular-nums;
    letter-spacing: -0.01em;
  }
  ```
- **kbd (клавиши):** моно, 10px, рамка с `border-bottom-width: 2px`, мягкий фон.

### 5.3. Иерархия
Строится **размером и весом**, не цветом.
| Уровень | Пример | Стиль |
|---------|--------|-------|
| Крупный заголовок | название месяца/раздела | ~28–32px, вес 700 |
| Заголовок карточки | имя задачи/артефакта | ~0.9rem, вес 500, line-height 1.4 |
| Идентификатор | `#41080`, `FR-001` | моно, ~0.7rem, вес 600, tabular-nums |
| Служебная подпись | «ПЛАН», «ФАКТ» | бровь (см. выше), приглушённая |
| Основной текст | тело | ~14px, вес 400–450 |

## 6. Форма и глубина

### 6.1. Радиусы
| Токен | Значение | Применение |
|-------|----------|------------|
| `--radius-sm` | `8px` | мелкие элементы, чипы |
| `--radius-md` | `10px` | **контролы**: кнопки, поля |
| `--radius` (база) | `12px` | общий |
| `--radius-card` | `14px` | карточки |
| диалог | `16px` | модалки/шиты |
| пилл | `9999px` | статусы, бейджи, аватары |

Скругления заметные, но не «таблетки»: мягко, аккуратно, подтянуто.

### 6.2. Тени (тёплый чёрный, минимализм)
Три уровня (значения — в CSS §4.5):
- **card** — базовая, почти незаметная (лежит на поверхности).
- **raise** — при ховере/поднятии карточки.
- **pop** — для всплывающих слоёв (меню, поповеры).

⚠️ Тени тёплые (`rgba(28,22,14,…)` в свете), очень сдержанные. Никаких жёстких/цветных теней. Часто вместо тени у карточки — тонкая рамка `0 0 0 1px` из `--border` с прозрачностью.

### 6.3. Границы и разделители
- Волосяная линия `1px` цвета `--border`.
- Разделитель в шапке: вертикальная линия `1px`, высота ~20px, цвет `--border` (`.header-divider`).
- Акцентный разделитель под шапкой: тонкий градиент от прозрачного к чернилам и обратно, прозрачность ~0.3.

## 7. Движение

### 7.1. Фирменный easing
- **Основной:** `cubic-bezier(0.16, 1, 0.3, 1)` — быстрый старт, мягкое приземление. Использовать почти везде.
- **Пружинка (для мобильных FAB/иконок):** `cubic-bezier(0.34, 1.56, 0.64, 1)` — лёгкий «перелёт».
- Длительности: `0.25–0.45s` для появлений, `0.1–0.2s` для микро-откликов.

### 7.2. Микро-отклики (обязательные)
- Нажатие кнопки: `transform: scale(0.97)` (для акцентных кнопок `scale(0.98)`).
- Ховер карточки: `translateY(-1px)` + переход к `--shadow-raise`.
- FAB нажатие: `scale(0.92)`.
- Фокус с клавиатуры: `outline: 2px solid` акцент, `outline-offset: 2px`, радиус 6px.

### 7.3. Появление контента (каскад)
Готовые паттерны:
```css
@keyframes fade-in     { from { opacity: 0 } to { opacity: 1 } }
@keyframes fade-in-up  { from { opacity: 0; transform: translateY(16px) } to { opacity: 1; transform: none } }
@keyframes scale-in    { from { opacity: 0; transform: scale(0.92) } to { opacity: 1; transform: scale(1) } }
@keyframes view-enter  { from { opacity: 0; transform: translateY(8px) } to { opacity: 1; transform: none } }
@keyframes rail-enter  { from { opacity: 0; transform: translateX(-10px) } to { opacity: 1; transform: none } }

.animate-fade-in    { animation: fade-in 0.3s ease-out; }
.animate-fade-in-up { animation: fade-in-up 0.4s cubic-bezier(0.16,1,0.3,1); }
.view-enter         { animation: view-enter 0.32s cubic-bezier(0.16,1,0.3,1) both; }
.rail-enter         { animation: rail-enter 0.45s cubic-bezier(0.16,1,0.3,1) both; }
```
- **Каскад дочерних** (`.stagger > *`): нарастающая задержка `0.02s → 0.26s` по 3ms-шагам — списки/карточки «проявляются» по очереди.
- **Brand Splash:** контур дельты рисуется штрихом (`stroke-dashoffset`), затем «дыхание» стека дельт (`scale 1 → 1.015`, ~7s).

### 7.4. Доступность
⚠️ Обязательно уважать `prefers-reduced-motion: reduce` — сводить анимации к ~0.01ms:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 8. Рецепты компонентов

Базовые компоненты в языке Delta. Значения — из эталона; используй как отправную точку.

### 8.1. Карточка
- Фон `--card`, скругление `--radius-card` (14px), падинг ~18–20px.
- Глубина: либо `--shadow-card`, либо тонкая рамка `0 0 0 1px` из `--border` (70% прозрачности) — без «жирных» границ.
- Ховер: `translateY(-1px)` + `--shadow-raise` + чуть подкрашенная граница.
- Выделение (selected): рамка цвета акцента + мягкое кольцо `0 0 0 3px` акцент/14%. Опционально — тонкая акцентная полоска слева (`::before`, ширина 0 → 5px при выделении).
```css
.card {
  background: var(--card);
  border-radius: var(--radius-card);
  padding: 18px 20px;
  box-shadow: var(--shadow-card);
  transition: box-shadow .16s ease, transform .16s ease, border-color .16s ease;
}
.card:hover { transform: translateY(-1px); box-shadow: var(--shadow-raise); }
```

### 8.2. Кнопка
- **Primary:** фон `--primary` (чернила/бумага по теме), текст `--primary-foreground`, скругление 10px. Тень `0 2px 8px` акцент/28%; ховер `translateY(-1px)` + тень 36%; нажатие `translateY(0)` + `scale(0.98)`.
- **Ghost/secondary:** прозрачный фон, текст `--foreground`; ховер — `--accent-soft`.
- Иконки в кнопках — `lucide-react`, тонкие, 16px.

### 8.3. Поле ввода
- Высота ~32–36px, скругление 6–10px, рамка `--border`, фон `--card`/`--background`.
- Фокус: рамка акцент/55% + кольцо `0 0 0 3px` акцент/14%. Без «синих» дефолтных обводок.
```css
.field {
  height: 32px; padding: 0 8px; font-size: .75rem;
  border-radius: 6px; border: 1px solid var(--border);
  background: var(--card); color: var(--foreground); outline: none;
  transition: border-color .15s, box-shadow .15s;
}
.field:focus { border-color: var(--primary); box-shadow: 0 0 0 3px color-mix(in srgb, var(--primary) 14%, transparent); }
```

### 8.4. Статус / бейдж (pill)
- Полное скругление, кегль ~0.65rem, вес 600, падинг `2px 7px`.
- Цвет — из семантики (§4.4): насыщенный текст + мягкий тонированный фон того же тона. Нейтральный статус — `--text-muted` на `--accent-soft`.

### 8.5. Пустое состояние
- Иконка в мягком скруглённом квадрате (52px, радиус 16px, фон `--accent-bg`, цвет акцента) → заголовок 14px/600 → подсказка 12px `--text-muted`, ширина ≤260px, `line-height: 1.5`. Центрировано, падинг ~56px.

### 8.6. Меню / поповер
- На бумаге: фон `--popover`, тень `--shadow-pop`, рамка `--border`, радиус 12px.
- Меню «с рельсы» — графитовые (Ink Pop / Ink Ctx, §4.3): тёмный фон, инверсный ховер у контекстного меню.

### 8.7. Скроллбар
- Тонкий (5–8px), thumb — смесь `--text-muted`/`--border` (~28%), радиус 9999px, ховер темнее. Трек прозрачный. И `scrollbar-width: thin` для Firefox.

### 8.8. Выделение текста
```css
::selection { background: color-mix(in srgb, var(--primary) 22%, transparent); color: inherit; }
```

## 9. Раскладка и пространство

- **Много воздуха.** Щедрые отступы между секциями и карточками; чистые поверхности.
- **Сетки карточек:** `repeat(auto-fill, minmax(~320px, 1fr))`, gap ~10–12px.
- **Группировка смыслом:** секции с тонкой цветной вертикальной меткой слева (например, приоритеты) — цвет метки семантический.
- **Рельса (если продукт её использует):** узкая, графитовая, слева; логотип-△ сверху; пункты с моно-«бровями»; активный — белая плашка; утилиты и профиль снизу. Неактивные пункты — с бейджем «Скоро».
- **Шапка:** крупный заголовок, широкий поиск, ряд действий (фильтр/сортировка слева — первичные кнопки справа), сводка метрик моноширинными числами.
- **Мобайл:** нижняя навигация на графите (`#17181C`), FAB-кнопка (52px, круг, акцент), touch-таргеты ≥44px, safe-area padding.

> Раскладка может отличаться от продукта к продукту (у трекера — рельса, у другого продукта — светлое пространство без сайдбара). Едина не раскладка, а **язык**: цвет, шрифт, форма, движение, рельса-как-дверь.

## 10. Да / Нет (чтобы это оставалось Delta)

**Да:**
- Монохромный хром (чернила/бумага), цвет — только у статусов/прогресса/опасности.
- Geist + Geist Mono; моно-«брови» капсом с разрядкой; табличные числа.
- Мягкие скругления 10/12/14/16; тёплые сдержанные тени; тонкие волосяные границы.
- Графитовая рельса/шапка с белой плашкой активного пункта.
- Фирменный easing `cubic-bezier(0.16,1,0.3,1)`; лёгкие микро-отклики на нажатие/ховер.
- Много воздуха; иерархия размером и весом.

**Нет:**
- Произвольные/разноцветные акценты, декоративные градиенты, «неоновые» цвета.
- Цвет без смысла; более одного «рабочего» цвета для прогресса.
- Жёсткие/цветные тени, толстые яркие рамки.
- Пёстрая типографика, отсутствие моно для чисел, заголовки цветом вместо веса.
- Тесная плотная вёрстка без воздуха.
- Резкие/долгие анимации; игнор `prefers-reduced-motion`.

## 11. Ink-система (обязательная для продуктов с рельсой)

Ink-система — набор CSS-классов, обеспечивающих фирменный вид графитовых элементов: рельса, меню, контекстные меню, тёмные блоки. **Обязательна** для любых продуктов Delta, использующих боковую навигацию.

### 11.1. Ink Rail (графитовая рельса)

Класс `.ink-rail` или `data-mobile="true"` на сайдбаре. Замораживает ВСЕ темпеременные на тёмные значения внутри рельсы:

```css
.ink-rail {
  --rail-bg: #17181C;
  --rail-text: #FAFAF8;
  --rail-muted: rgba(250,250,248,0.74);
  --rail-faint: rgba(250,250,248,0.50);
  --rail-line: rgba(250,250,248,0.12);
  --rail-hover: rgba(250,250,248,0.08);

  /* shadcn-токены сайдбара */
  --sidebar: var(--rail-bg);
  --sidebar-foreground: var(--rail-text);
  --sidebar-border: var(--rail-line);
  --sidebar-accent: var(--rail-hover);

  /* Страховка: все переменные темы на тёмные */
  --background: #131418;
  --foreground: #F5F5F2;
  --card: #1A1B20;
  --primary: #F5F5F2;
  --primary-foreground: #17181C;
  --border: #34353C;

  background: #17181C !important;
  color: #FAFAF8 !important;
  color-scheme: dark !important;
}
```

**Активный пункт навигации** — белая плашка с чёрным текстом, всегда:
```css
.rail-nav[data-active="true"],
.ink-rail [data-active="true"][data-slot="sidebar-menu-button"] {
  color: #17181C !important;
  background: #FAFAF8 !important;
}
```

### 11.2. Ink Pop (меню с рельсы)

Обычные выпадающие меню (аккаунт, домен, год):

```css
.ink-pop {
  --popover: #1C1D22;
  --popover-foreground: #FAFAF8;
  --accent: rgba(250, 250, 248, 0.09);
  --border: rgba(250, 250, 248, 0.14);
  background: #1C1D22 !important;
  color: #FAFAF8;
  border-color: rgba(250, 250, 248, 0.14) !important;
  box-shadow: 0 12px 36px -8px rgba(0, 0, 0, 0.55), 0 3px 10px rgba(0, 0, 0, 0.35) !important;
}
```

### 11.3. Ink Ctx (контекстное меню)

Чистое ЧБ-контекстное меню с инверсией при ховере:

```css
.ink-ctx {
  --popover: #0F1013;
  --popover-foreground: #FAFAF8;
  --accent: #FAFAF8;
  --accent-foreground: #0F1013;
  --destructive: #FF4444;
  background: #0F1013 !important;
  border: 1px solid rgba(250, 250, 248, 0.10) !important;
  border-radius: 12px !important;
}
/* Ховер — инверсия: белый фон, чёрный текст */
.ink-ctx [data-slot="context-menu-item"]:hover {
  background: #FAFAF8 !important;
  color: #0F1013 !important;
}
/* Удалить — красный при ховере */
.ink-ctx [data-slot="context-menu-item"][data-variant="destructive"]:hover {
```

Целый блок (настройки, тосты, панели) всегда в графите:

```css

  --foreground: #F5F5F2;
```

## 13. Архитектура темы

### 13.1. Два допустимых подхода

**Подход A: Статичные CSS-переменные** (рекомендуемый)
- Все токены заданы в `:root` и `.dark` плоскими hex-значениями
- Переключение: класс `.dark` на `<html>` (`darkMode: "class"` в Tailwind)
- Преимущество: простота, предсказуемость, точное соответствие DNA
- Пример: Delta-BA (`src/index.css`)

**Подход B: Динамическая генерация через applyTheme()**
- Функция `createTheme()` возвращает объект с токенами
- `applyTheme()` записывает их в `document.documentElement.style`
- Преимущество: возможность расширения (если понадобится)
- Важно: темаDelta **фиксирована**, `baseHex` игнорируется
- Пример: Delta-tasker (`src/lib/theme.ts`)

### 13.2. Требование: только hex

⚠️ **Все значения токенов DNA заданы в hex.** При реализации:

- **Рекомендуется:** использовать hex напрямую (`#FAFAF8`, `#17181C`)
- **Допускается:** oklch() **ТОЛЬКО** если точное соответствие hex-значению проверено визуально и через инструменты (Figma, DevTools)
- **Запрещено:** использовать oklch-значения, которые отклоняются от DNA-hex (например, `oklch(0.145 0 0)` ≈ `#202020` вместо `#131418`)

### 13.3. Варианты именования токенов

DNA описывает **два совместимых именования**:

**Вариант A (shadcn-совместимый):** `--background`, `--foreground`, `--card`, `--primary`, `--muted-foreground`, `--border`, `--destructive`

**Вариант B ( Delta-BA стиль):** `--color-bg`, `--color-surface`, `--color-text`, `--color-text-secondary`, `--color-primary`, `--color-border`, `--color-error`

Оба допустимы. При выборе — придерживаться одного варианта внутри проекта.

## 14. Быстрый старт для нового продукта Delta

1. **Стек:** любой (React/Next/Vite/…). Токены — обычные CSS-переменные, работают везде. Иконки — `lucide-react`.
2. **Вставь токены:** блок CSS из §4.5 в глобальные стили (`:root` + `.dark`). Тёмная тема — класс `dark` на `<html>` (`darkMode: "class"` в Tailwind). Используй **hex-значения** (§13.2).
3. **Шрифты:** подключи Geist и Geist Mono, задай `--font-geist-sans` / `--font-geist-mono` (§5.1).
4. **Tailwind:** пробрось токены в тему. Для shadcn/ui — см. §12.3.
5. **Компоненты:** используй рецепты §8 как базу (карточка, кнопка, поле, пилл, меню, пустое состояние).
6. **Движение:** добавь keyframes и easing из §7; не забудь `prefers-reduced-motion`.
7. **Знак и рельса:** воспроизведи △-логотип и (если нужен сайдбар) графитовую рельсу с белой плашкой активного пункта — это делает продукт мгновенно «Delta».
8. **Ink-система:** для продуктов с рельсой — добавь классы `.ink-rail`, `.ink-pop`, `.ink-ctx`, `.ink-scope` из §11.
9. **Brand Splash:** добавь анимированную загрузку из §11.5 для узнаваемого входа.

## 15. Чек-лист «Это Delta?»

- [ ] Хром монохромный (чернила/бумага); цвет только у семантики.
- [ ] Светлая = бумага `#FAFAF8` + чернила `#17181C`; тёмная = графит `#131418` + текст `#F5F5F2`.
- [ ] Рельса/шапка графитовая `#17181C`; активный пункт — белая плашка, чёрный текст.
- [ ] Шрифты Geist + Geist Mono; «брови» капсом с разрядкой; числа моноширинные табличные.
- [ ] Радиусы 8/10/12/14/16 + pill; тёплые сдержанные тени; волосяные границы.
- [ ] Фирменный easing `cubic-bezier(0.16,1,0.3,1)`; нажатие `scale(0.97)`, ховер карточки `translateY(-1px)`.
- [ ] Много воздуха; иерархия размером/весом, а не цветом.
- [ ] `prefers-reduced-motion` уважается; фокус — чернильное кольцо 2px, **сплошное** (без прозрачности).
- [ ] △-знак и Brand Splash в графите-бумаге (§11.5).
- [ ] Ink-система реализована: `.ink-rail`, `.ink-pop`, `.ink-ctx`, `.ink-scope` (§11).
- [ ] Токены заданы в **hex** (§13.2); oklch допустим только с проверкой соответствия.
- [ ] Selection: `22%` opacity (§8.8).
