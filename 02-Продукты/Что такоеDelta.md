# Что такоеDelta

**Delta** — это семейство профессиональных инструментов для бизнес-аналитиков и руководителей проектов.

---

## ЭкосистемаDelta

```
DataBase (база знаний)
    ↓
Delta-BA (помощник аналитика)  ←→  Delta-tasker (трекер задач)
    ↓                                   ↓
  ТЗ, чеклисты, BPMN,              Задачи, презентации,
  протоколы, мокапы                дашборды, KPI
```

Все продукты объединены:
- Единым дизайном «Графит и бумага»
- Общей базой знаний (DataBase)
- Похожим функционалом для бизнес-аналитиков

---

## Продукты

### [[Delta-BA|Delta-BA — Помощник аналитика]]

ИИ-инструмент для автоматизации рутинной работы аналитика:
- Генерация ТЗ из описания
- Чеклисты тестирования
- BPMN-диаграммы
- Протоколы встреч
- HTML-мокапы
- Excel-расчёты

**Стек:** React 19, Vite 8, Tailwind CSS 4

### [[Delta-tasker|Delta-tasker — Трекер задач]]

Операционный монитор дляBA и руководителей:
- Таблица задач с приоритетами
- Backlog (очередь)
- Вопросы/ответы
- Презентации (слайды)
- Дашборд с KPI

**Стек:** Next.js 16, shadcn/ui, Prisma, PostgreSQL

---

## Дизайн

Все продукты следуют [[Delta_Design_DNA|единому стилю]]:

- **Монохром** — чернила на бумаге
- **Цвет** — только для статусов и прогресса
- **Графитовая рельса** — `#17181C`
- **Шрифты** — Geist + Geist Mono
