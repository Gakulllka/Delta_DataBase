# Delta-finance — Персональный финансовый трекер

> Мобильное приложение для трекинга личных финансов с Котом Delta — питомцем, который растёт вместе с твоими целями.

---

## Что умеет

| Функция | Описание |
|---------|----------|
| **Доходы** | Зарплата, отпускные, больничные, доп. доход |
| **Расходы** | Транспорт, еда, жильё, развлечения, другое |
| **Цели (Мечты)** | Накопление на конкретные покупки/события |
| **Кот Delta** | Питомец, эволюционирует с прогрессом цели |
| **Дашборды** | KPI, графики, кастомные виджеты |
| **Авторизация** | Раздельные данные между пользователями |

---

## Кот Delta — Эволюция

| Прогресс | Состояние | Описание |
|----------|-----------|----------|
| 0–25% | 🐱 Спит | Свернулся клубком |
| 25–50% | 🐱 Сидит | Открыл глаза, смотрит |
| 50–75% | 🐱 Играет | Играет с клубком |
| 75–100% | 🐱 Радуется | Мурчит, доволен |

---

## Как пользоваться

1. **Войди или зарегистрируйся** — личные данные защищены
2. **Добавь доходы** — зарплату, отпускные, доп. доход
3. **Следи за расходами** — категоризируй траты
4. **Поставь цель** — укажи сумму и дедлайн
5. **Наблюдай за котом** — чем быстрее накапливаешь, тем счастливее кот
