# Что такое Delta

**Delta** — семейство инструментов для бизнес-аналитика и руководителя проектов. Продукты независимы: у каждого свой репозиторий, стек и деплой. Объединяют их три вещи — единый визуальный язык, общая база знаний и общий свод правил для ИИ-агентов.

---

## Карта экосистемы

```
              ┌─────────────────┐
              │   Delta-hub     │   витрина: карточки продуктов
              └────────┬────────┘
             ┌─────────┴─────────┐
             ▼                   ▼
     ┌───────────────┐   ┌───────────────┐
     │   Delta-BA    │   │ Delta-tasker  │
     │  ТЗ, BPMN,    │   │ задачи, часы, │
     │  чеклисты,    │   │ бюджет месяца,│
     │  протоколы,   │   │ презентации   │
     │  прототипы    │   │               │
     └───────────────┘   └───────────────┘

     ┌───────────────┐   ┌───────────────┐
     │ Delta-finance │   │   DataBase    │
     │ (вне периметра│   │ этот vault    │
     │  ревизии)     │   │               │
     └───────────────┘   └───────────────┘
```

> [!important] Продукты между собой не интегрированы
> Единственная связь в коде — кнопка **HUB** в шапке Delta-BA и в рельсе Delta-tasker, ведущая на `delta-hub-alpha.vercel.app`. Обмена данными между BA и tasker нет: разные хранилища, разные модели, общего API нет.

## Продукты

### [[Delta-hub]] — витрина

Одностраничный лаунчер. Brand Splash 2,8 с, затем две карточки продуктов со ссылками на прод и резерв. Переключатель темы. Своих данных не имеет.

**Стек:** React 19 · Vite 6 · Tailwind 4. Весь `src/` — 474 строки.

### [[Delta-BA]] — помощник аналитика

SPA без бэкенда. Шесть ИИ-модулей: генератор ТЗ, тест-чеклист, BPMN, протокол совещаний, Excel-расчётчик, HTML-прототип. Артефакты связываются через единое хранилище, цикл «ТЗ → чеклист → доработочное ТЗ» замыкается.

**Стек:** React 19 · Vite 8 · Tailwind 4 · React Router 7. Данные — `localStorage`, опционально Supabase.

### [[Delta-tasker]] — операционный монитор

Полноценное приложение с БД. Ядро — месячный бюджет часов между аналитиком и руководителем: план и факт по каждой задаче, лимит месяца на домен, алгоритм отсечения при перерасходе, двусторонние сигналы. Итог месяца — версионируемая презентация.

**Стек:** Next.js 16 · Prisma · PostgreSQL · shadcn/ui · Zustand · Recharts.

### [[Delta-finance]] — личные финансы

Вне периметра ревизии 2026-08-09. См. карточку.
