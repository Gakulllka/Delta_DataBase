# Delta-hub — Центральный навигатор

> Главная точка входа в экосистемуDelta. Карточки продуктов с переходом вDelta-BA иDelta-tasker.

---

## Что умеет

| Функция | Описание |
|---------|----------|
| **Навигация** | Быстрый переход в любой продуктDelta |
| **Карточки** | Описание каждого продукта с кнопкой «Открыть» |
| **Тема** | Переключатель свет/тьма (сохраняется в localStorage) |
| **Brand Splash** | Анимированный логотип при загрузке |

---

## Как пользоваться

1. **ОткройDelta Hub** — главная страница экосистемы
2. **Выбери продукт** — нажми на карточкуDelta-BA илиDelta-tasker
3. **Перейди** — откроется в новой вкладке

### Brand Splash — эталонная реализация

Delta-hub содержит **эталонный Brand Splash** для всей экосистемы:

- **Фон:** графитовый `#17181C`
- **Логотип:** три вложенных треугольника (△):
  - Внешний: opacity 0.3, тонкий штрих
  - Средний: opacity 0.6
  - Внутренний:.opacity 1, жирный штрих (3px)
- **Анимация:** прорисовка контура (`stroke-dashoffset`) + «дыхание» стека дельт
- **Прогресс-бар:** тонкая линия с анимацией скольжения
- **Длительность:** 2.8 секунды

**Реализация:** `src/components/BrandSplash.tsx`
