## Запуск

```bash
npm run dev      # vite --port 3000  (strictPort: true)
npm run build    # tsc && vite build
npm run preview
```

> [!note] Порт фиксирован
> `strictPort: true` — порт не подбирается автоматически, при занятом `:3000` сборка падает. `:3000` закреплён за hub, [[Delta-tasker]] работает на `:3003`.

**Чего в проекте нет:** линтера, тестов, CI.

## Дизайн

Самая точная реализация [[Delta_Design_DNA|ДНК]] из трёх проверенных продуктов: токены заданы плоским hex и совпадают с каноном **до значения**.

| Проверка | Результат |
|----------|-----------|
| Токены светлой темы | `#FAFAF8` · `#FFFFFF` · `#17181C` · `#DEDDD6` — совпадают |
| Токены тёмной темы | `#131418` · `#1A1B20` · `#F5F5F2` · `#34353C` — совпадают |
| Easing | `cubic-bezier(0.16, 1, 0.3, 1)` — совпадает |
| Названия анимаций | `fade-in`, `fade-in-up` — совпадают |
| Selection | 22 % — совпадает |
| Focus ring | `2px solid var(--primary)`, сплошной — совпадает |
| Скроллбар | 8 px, thumb 32 % — в допуске |
| `prefers-reduced-motion` | учтён |
| Нажатие | `scale(0.98)` для всех — ДНК просит `0.97` для обычных |

Рельсы и Ink-системы нет — продукт одноэкранный, сайдбара не существует. Не отступление, а неприменимость.

**Brand Splash здесь эталонный** — три вложенных △ на графите `#17181C` штрихом `#FAFAF8`: внешний «дышит» (`brand-hero-breathe`, 7 с), средний прорисовывается через `stroke-dasharray` (`brand-delta-draw`, 2,4 с), внутренний статичен на 25 % прозрачности.

## Известные расхождения

1. **`strictPort: true`** — при занятом `:3000` hub не стартует, а не подбирает свободный порт.
2. **Delta-finance отсутствует в витрине** — при том, что продукт существует.
3. **`scale(0.98)` вместо `0.97`** для обычных кнопок.
4. **Нет линтера и CI** — единственный проект экосистемы без автоматических проверок.
