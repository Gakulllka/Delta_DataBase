# Промпты-агентов

> Карта AGENTS-файлов экосистемы Delta. Сами файлы физически лежат **вне** vault — рядом с кодом каждого проекта. Эта страница — указатель и объяснение иерархии.

---

## Два уровня промптов

Промпты для ИИ организованы в два уровня. Каждый имеет свою зону ответственности и не дублирует другой.

### Уровень 1 — Общий промпт экосистемы

**Файл:** `C:\Delta\AGENTS.md`

Правила, общие для **всех** проектов:
- русский язык коммуникации и интерфейсов;
- запрет `git push` без явного разрешения пользователя;
- единый визуальный стиль «Графит и бумага» ([[Delta_Design_DNA|ДНК]]);
- порядок исследования (DataBase → промпты → код);
- технические предохранители (Tailwind CSS v4, Vite + TypeScript);
- синхронизация изменений с DataBase и журнал [[Ошибки|ошибок]].

### Уровень 2 — Проектный промпт

**Файл:** `Delta-{проект}/AGENTS.md` — один в корне каждого проекта.

Специфика **одного** проекта: точный стек и версии, архитектура и границы слоёв, команды запуска и проверки, роли/БД/синхронизация, запрещённые действия, уникальные ограничения.

## Порядок чтения

При работе с проектом читай строго в порядке:

1. Общий промпт (`C:\Delta\AGENTS.md`)
2. Проектный промпт (`Delta-{проект}/AGENTS.md`)
3. Исходный код проекта

Общий промпт задаёт рамку, проектный — наполняет её деталями конкретного проекта. При конфликте правил **проектный промпт уточняет, но не отменяет** общий.

---

## Сквозные принципы

Задаются общим промптом, повторяются проектными:
- Минимальные изменения — никакого побочного рефакторинга.
- Запрет `any` / `@ts-ignore` / `@ts-expect-error`.
- Русский язык интерфейсов и коммуникации.
- Обратная совместимость данных.
- Честный отчёт — не писать «всё работает», если не проверено.

---

## Почему промпты вне vault

AGENTS-файлы лежат рядом с кодом, а не в `03-ИИ/`, потому что:
- проектный промпт описывает специфику **именно этого** проекта и должен эволюционировать вместе с кодом;
- инструменты ИИ (ZCode, иные агенты) ищут `AGENTS.md` в корне проекта автоматически;
- vault хранит **теорию** (дизайн-система, документация продуктов), промпты — **инструкции по работе**.

В `03-ИИ/` хранятся только эта карта и [[Ошибки|журнал ошибок]].
