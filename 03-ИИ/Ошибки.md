## Журнал ошибок

### 2026-07-25 — Tailwind CSS v4: PostCSS plugin moved

**Продукт:** Delta-hub

**Сообщение:**
```
It looks like you're trying to use `tailwindcss` directly as a PostCSS plugin.
The PostCSS plugin has moved to a separate package, so to continue using Tailwind
CSS with PostCSS you'll need to install `@tailwindcss/postcss` and update your
PostCSS configuration.
```

**Причина:** Tailwind CSS v4 вынес PostCSS-плагин в отдельный пакет `@tailwindcss/postcss`. Старый синтаксис `tailwindcss: {}` в `postcss.config.js` больше не работает.

**Решение:**
1. Установить пакет: `npm install @tailwindcss/postcss`
2. Обновить `postcss.config.js`:
```js
export default {
  plugins: {
    '@tailwindcss/postcss': {},  // вместо tailwindcss: {}
    autoprefixer: {},
  },
}
```

**Профилактика:** При использовании Tailwind CSS v4+ всегда проверять документацию на наличие миграционных изменений. Не копировать конфиги из v3 проектов без проверки.

### 2026-07-25 — Tailwind CSS v4: CSS syntax change

**Продукт:** Delta-finance

**Сообщение:**
```
Error evaluating Node.js code
Error: It looks like you're trying to use `tailwindcss` directly as a PostCSS plugin.
```

**Причина:** Повторная ошибка — в новом проекте был скопирован старый синтаксис CSS (`@tailwind base; @tailwind components; @tailwind utilities;`) вместо нового (`@import "tailwindcss"`).

**Решение:**
1. Установить пакет: `npm install @tailwindcss/postcss`
2. Обновить `postcss.config.js`:
```js
module.exports = {
  plugins: {
    '@tailwindcss/postcss': {},
    autoprefixer: {},
  },
}
```
3. Обновить `globals.css`:
```css
@import "tailwindcss";  /* вместо @tailwind base; @tailwind components; @tailwind utilities; */
```

**Профилактика:** При создании новых проектов на Tailwind v4:
- Всегда использовать `@import "tailwindcss"` вместо `@tailwind` директив
- Всегда использовать `@tailwindcss/postcss` в postcss.config.js
- Не копировать CSS из v3 проектов

### 2026-07-26 — TypeScript: Cannot find module './index.css'

**Продукт:** Delta-hub

**Сообщение:**
```
src/main.tsx(5,8): error TS2307: Cannot find module './index.css' or its corresponding type declarations.
```

**Причина:** TypeScript не знает типы для CSS-модулей. Vite обрабатывает CSS, но TypeScript не имеет деклараций типов для импорта `.css` файлов.

**Решение:** Создать файл `src/vite-env.d.ts`:
```ts
/// <reference types="vite/client" />
```

**Профилактика:** При создании Vite + TypeScript проектов всегда добавлять `vite-env.d.ts` с декларацией типов Vite.
